# Milestones

Each milestone gets a folder `Mx/` with `requirements.md`, `design.md`,
`test-plan.md`, `demo.md`, and `retro.md` (see [`../templates/`](../templates/)).

| Milestone | Status |
|---|---|
| M0 Requirements and design | ✅ Released v0.1.0 (2026-10-16) |
| M1 Foundation and synthetic data | ✅ Released v0.2.0 (2026-10-16) |
| M2 Matching engine and eval harness | Requirements gate |
| M3 LLM client and extraction | Not started |
| M4 API, worker, fuzzy fallback | Not started |
| M5 Web UI and human-in-the-loop | Not started |
| M6 MCP server | Not started |
| M7 Deploy | Not started |

M0 is documentation-only. Its "requirements" are the PRD and its "design" is
`architecture.md` plus the ADRs, so its folder holds only the retro.
